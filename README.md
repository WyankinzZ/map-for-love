- **个人隐私绝对安全**：照片、情书、心愿与旅行记录完全保存在自己的手机与电脑本地，不经过任何第三方服务器，安心无忧；
- **手机端备份与跨端互通**：支持在手机端一键导出完整 JSON 备份并直接分享到微信/QQ，新设备（手机/电脑）一键无损导入还原。

### 🎨 核心视觉体系与交互全面升级
- **UI 全面重构并优化**：
  - **全站图标风格统一**：移除了原生大 Emoji，心愿清单、成就系统、纪念日与时光宝盒全站统一采用与时光宝盒一致的 Lucide 极简精致轮廓胶囊风格，视觉质感更加高级温润；

## 📦 多端运行与打包构建

本项目使用 **Next.js 16 (App Router)**、**React 19**、**Tailwind CSS 4**、**Electron** 及 **Capacitor**。

### 1. 本地开发调试

```bash
# 安装依赖
npm install

# 启动 Web 开发服务 (默认端口 3000 或 3002)
npm run dev
```

### 2. Windows 桌面端打包

```bash
# 构建 Next.js Standalone 产物并打包为 Windows x64 安装程序 (.exe)
npm run dist:win
```
> 打包成功后，产物位于 `dist/Map for Love-2.0.0-x64-Setup.exe`，免安装便携目录位于 `dist/win-unpacked/`。

### 3. Android APK 打包

```bash
# 1. 构建移动端静态资源并同步至 Android 工程
npm run build:mobile

# 2. 打开 Android Studio 进行调试或构建 Release/Debug APK
npx cap open android
```
> 或者直接在 `android/` 目录下运行 `./gradlew assembleDebug`，生成产物位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 🔒 数据存储与安全隐私

本项目秉持**“你的数据完全属于你”**的隐私原则，设计为双轨制存储架构：

1. **纯本地离线模式 (默认推荐)**：
   - 网页/移动端优先持久化于高容量的浏览器 **IndexedDB** 与本地存储；
   - 桌面端数据自动保存在系统的 Electron `userData` 路径下（例如 Windows 的 `%APPDATA%/Map for Love/data`）；
   - 所有照片与文本均留在用户本地，不经过任何外部服务器。

2. **阿里云 OSS 云端扩容模式 (可选)**：
   - 在设置中输入阿里云 OSS 的 `Region`、`Bucket` 和 `AccessKey`，所有新照片将直连上传至你的私有阿里云 Bucket；
   - 导出的 JSON 备份文件体积由几百兆大幅精简至数十 KB；
   - **隐私保护防泄漏**：OSS 密钥仅保存在本地 `.private.json` 中，被 Git 严格忽略，绝不上云、绝不随备份文件泄露。

## 💾 备份与跨设备迁移

在应用中进入 **系统设置 → 数据备份与恢复**：

1. **导出备份**：点击「导出完整备份」，将所有回忆记录、收藏、愿望、成就、纪念日和系统配置一键导出为单个 `.json` 文件。
2. **导入恢复**：在新电脑或新手机上打开应用，点击「导入备份」选取备份文件，即刻完美还原所有美好回忆。
3. **多端互通**：在手机端导出的备份文件可直接在电脑端无缝导入，反之亦然。
